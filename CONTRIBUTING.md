# Contributing to TeleMedLink

Thank you for your interest in contributing to TeleMedLink! We welcome contributions from the community.

## How to Contribute

### Reporting Bugs
- Check if the bug has already been reported in [Issues](../../issues)
- If not, create a new issue with a clear description and reproduction steps
- Include details about your environment (Python version, OS, etc.)

### Suggesting Enhancements
- Use [GitHub Issues](../../issues) to suggest features/improvements
- Provide a clear description and use cases for the enhancement
- Be open to feedback and discussion

### Pull Requests
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature-name`)
3. Make your changes with clear, descriptive commits
4. Write or update tests as needed
5. Update documentation if applicable
6. Push to your fork and submit a Pull Request
7. Describe your changes and link any related issues

## Coding Standards
- Follow PEP 8 conventions
- Write descriptive commit messages
- Include docstrings for functions and classes
- Test your changes locally before submitting

## Code of Conduct
This project adheres to the [Contributor Covenant Code of Conduct](./CODE_OF_CONDUCT.md). We expect all contributors to uphold this code.

## Questions or Need Help?
- Open an issue with the `question` label
- Check existing documentation in the `docs/` folder
- Review the project architecture in `HARMONIZATION_PROCESS.txt`

Thank you for contributing to better healthcare technology! 🏥
